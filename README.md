# 검토용 시안 (가칭 업체)

이 저장소의 페이지는 **검토용 시안**입니다.

- 상호(가칭)와 전화번호는 실제 업체의 것이 아닙니다. 전화번호는 연결되지 않습니다.
- **실제 업체가 아닙니다.** 가격과 업체 정보는 모두 확인 전의 임시 값입니다.
- **예시 후기**는 시안용으로 만든 글이며 실제 고객 후기가 아닙니다.
- 사진은 **AI 연출 사진**이며 실제 시공 사진이 아닙니다.
- 페이지에는 검색 노출 차단(noindex)이 걸려 있습니다. 이것은 **비공개가 아닙니다.** 공개 저장소의 파일은 누구나 볼 수 있습니다.
